# Мастер замков — отчёты по рекламе

Клиентский отчёт за октябрь 2026: расходы рекламы, обращения и оплаты CRM, города, причины отказов и сценарии увеличения бюджета. Оформление: белый фон, чёрный текст, жёлтый акцент сайта `#ffb917`.

## Публикация GitHub Pages

В настройках репозитория открыть **Settings → Pages → Build and deployment** и выбрать:

- **Source: Deploy from a branch**
- **Branch: main**
- **Folder: / (root)**
- **Save**

После успешной сборки главная страница отчёта будет доступна по адресу `https://samfinstat.github.io/masterzamkov/`, архив октября — `https://samfinstat.github.io/masterzamkov/reports/2026-10.html`. До настройки Pages эти адреса не считаются опубликованными.

## Содержимое

- `index.html`, `assets/`, `reports/2026-10.html` — готовые страницы для GitHub Pages.
- `data/2026-10.json` — агрегированные данные октября.
- `template.html` — шаблон отчёта.
- `scripts/build.mjs` — сборка главной и архивной страниц.
- `scripts/verify.mjs` — проверка расчётов и файлов.

## Обновление

```bash
node scripts/build.mjs
node scripts/verify.mjs
```

Новые месяцы добавляются отдельными файлами данных и отдельными архивными страницами; главная показывает последний отчёт. Для нового месяца нужно добавить его в сборщик и обновить датированные подписи. Октябрь не удалять.

## Методика

Срез CRM — 30.10.2026. Учитываются сделки согласованных источников «Юра», созданные в октябре; Волгоград включён. Повторы включены по согласованной методике. В сводке 151 сделка, 51 оплаченная на 198 500 ₽. Расходы рекламы с НДС — 93 885,92 ₽. Разница после рекламы — 104 614,08 ₽ до выплат мастерам и других расходов.

Сумма оплат — сумма сделок в стадии «Оплачен», а не банковская выписка всех поступлений за октябрь. Поле расходов `null` означает отсутствие кампании в выгрузке; настоящий нулевой расход записан как `0`. Причины закрытия сгруппированы по одной основной причине на сделку.

Прогноз опирается на Самару, Саратов и Волгоград. Будущая доля бюджета 50/30/20 и изменение стоимости оплаченной сделки на 20% — сценарные допущения. Для новых городов приняты 2 500–3 000 ₽ за оплату и средняя сумма заказа 3 500 ₽. Прогноз не является гарантией результата или расчётом чистой прибыли.

В репозитории только агрегированные показатели. Вебхук, данные контактов, адреса и записи разговоров не публикуются.
